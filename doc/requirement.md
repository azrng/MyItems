## 1. 项目概述

### 1.1 定位

个人/家庭自用的 Android 物品管理 App，核心功能是跟踪物品的保质期，同时管理物品的购入、存放等信息。到期追踪是核心亮点功能，但不是唯一功能。

### 1.2 目标用户

个人/家庭自用，不上架应用商店。

### 1.3 物品类型

覆盖所有类型：
- 食品/饮料（有保质期）
- 化妆品/护肤品（有保质期）
- 药品/保健品（有保质期）
- 日用品（电池、清洁剂等，部分有保质期）
- 耐用品（显示器、电器等，无保质期）

## 2. 功能需求

### 2.1 核心功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 物品录入（手动） | 表单填写物品名称、分类、购入价格、存放位置、过期日期等 | P0 |
| 物品录入（扫码） | 扫条形码调用 Open Food Facts API 自动填充 | P0 |
| 主页到期提醒 | 按过期/临期/安全/无期限分组展示，到期追踪为核心功能 | P0 |
| 物品库 | 所有物品去重展示，点击查看该物品所有批次和详情 | P0 |
| 分类管理 | 预置分类 + 自定义分类 CRUD | P0 |
| 数据导出/导入 | Excel 格式（.xlsx）导入导出，支持备份恢复 | P1 |
| 搜索 | 按物品名称搜索 | P1 |
| 存放位置管理 | 记录和筛选物品存放位置 | P2 |
| 统计概览 | 物品数量、花费统计、临期/过期统计 | P2 |

### 2.2 不在范围内（MVP）

- 推送通知（仅打开时查看）
- 云端同步
- 多用户/账号系统
- OCR 识别
- 上架应用商店相关（多语言、隐私合规等）

## 4. 业务规则

### 4.1 状态判断

基于 Batch 的 ExpiryDate 计算保质期状态：

| 状态 | 条件 | 颜色 |
|------|------|------|
| 已过期 | ExpiryDate < 今天 | 红色 |
| 临期 | 今天 <= ExpiryDate <= 今天+7天 | 黄色 |
| 安全 | ExpiryDate > 今天+7天 | 绿色 |
| 无保质期 | ExpiryDate 为 null | 蓝色 |

**主页排序规则：** 按保质期状态分组排序（过期 → 临期 → 安全 → 无保质期），每组内按日期升序。

### 4.2 录入流程

1. 用户点击"添加"，填写物品信息
2. 保存时系统检查是否存在同名物品
   - **同名存在** → 弹窗确认："已存在同名物品「xxx」，是否关联？"
     - 选择"关联" → 链接到已有 Item，新建 Batch（自动生成批次标签）
     - 选择"新建" → 创建新 Item + 新 Batch
   - **同名不存在** → 创建新 Item + 新 Batch
3. 批次标签自动用时间戳生成（如 "2026-05-02 14:30"）

### 4.3 扫码流程

1. 点击扫码按钮 → 打开摄像头 → 扫到条形码
2. 调用 Open Food Facts API 查询商品信息
3. 本地已有该条形码的物品 → 自动关联，用户只需填写批次信息
4. 新商品 → 自动填充名称，用户补充分类、过期日期等

### 4.4 删除规则

- 物品删除 → 软删除（IsArchived = true），不物理删除
- 批次删除 → 物理删除
- 预置分类不可删除，自定义分类可删除（需确认该分类下无物品）

## 5. 页面设计

## 7. 数据导出格式

导出为 Excel 文件（.xlsx），使用 ClosedXML 库生成，包含以下工作表：

**Sheet 1：分类**
| 列 | 类型 | 说明 |
|---|---|---|
| 分类名称 | string | 食品/饮料 |
| 图标 | string | 🍔 |
| 排序 | int | 1 |
| 是否预置 | bool | true |

**Sheet 2：物品**
| 列 | 类型 | 说明 |
|---|---|---|
| 物品名称 | string | 纯牛奶 |
| 分类 | string | 食品/饮料 |
| 品牌 | string | 蒙牛 |
| 条形码 | string | 6901234567890 |
| 默认存放位置 | string | 冰箱上层 |
| 创建时间 | DateTime | 2026-05-02 |

**Sheet 3：批次**
| 列 | 类型 | 说明 |
|---|---|---|
| 物品名称 | string | 纯牛奶 |
| 购买日期 | DateTime | 2026-03-01 |
| 购入价格 | decimal | 15.5 |
| 保质期 | DateTime | 2026-04-28 |
| 存放位置 | string | 冰箱上层 |
| 数量 | int | 2 |
| 备注 | string | 整箱购买 |
| 批次标签 | string | 2026-03-01 10:00 |
| 每日成本 | decimal | 0.52 |

**导入规则：**
- 预置分类按名称匹配，不重复创建
- 物品按名称判断，已存在则跳过或覆盖（由用户选择）
- 批次按批次标签判断，已存在则跳过

## 8. 非功能需求

| 项目 | 要求 |
|------|------|
| 启动速度 | 冷启动 < 2 秒 |
| 数据量 | 支持至少 1000 条批次记录无卡顿 |
| 数据安全 | 本地存储，无网络传输（除扫码查询 API） |
| 备份 | 支持手动导出 Excel 到本地文件系统 |
