## 1. 架构设计

### 1.1 技术选型

| 类别 | 选型 | 版本 |
|------|------|------|
| 框架 | .NET MAUI | .NET 10 |
| 语言 | C# | 13 |
| 架构模式 | MVVM | CommunityToolkit.Mvvm |
| UI 控件库 | Syncfusion.Maui.Toolkit | 最新 |
| 本地数据库 | SQLite (sqlite-net-pcl) | 最新 |
| 扫码 | ZXing.Net.Maui.Controls | 0.7.* |
| Excel 导出 | ClosedXML | 最新 |
| 目标平台 | Android 8.0+ (API 26) | net10.0-android |

### 1.3 数据流向

```
View (XAML)
  │ Binding
  ▼
ViewModel (ObservableObject + [ObservableProperty])
  │ 调用
  ▼
Service (MockDataService → DatabaseService)
  │ 映射
  ▼
Model / DTO
```

- Phase 1：ViewModel 直接调用 `MockDataService` 静态方法，返回硬编码数据
- Phase 2：ViewModel 注入 `DatabaseService`，通过 SQLite 增删改查

### 1.4 导航架构

使用 MAUI Shell 的 TabBar + FlyoutItem 混合结构：

```
AppShell (Shell)
├── FlyoutHeader: 📦 我的物品 / 物品管理助手
├── TabBar (底部标签栏)
│   ├── Tab: 主页 → MainPage（仅显示过期+临期）
│   ├── Tab: 物品库 → ItemLibraryPage（含统计卡片）
│   └── Tab: 分类 → CategoryPage
├── FlyoutItem: 添加 → AddItemPage（侧边栏入口）
├── ShellContent (Route): ItemDetailPage
└── MenuItem: 关于 → AboutPage (Route)
```

- 底部 TabBar 提供 3 个主要页面快速切换
- 添加页面通过侧边栏（Flyout）访问
- ItemDetailPage 通过 `GoToAsync("itemdetail?itemId=xxx")` 导航
- AboutPage 通过 `GoToAsync(nameof(AboutPage))` 导航

### 1.5 设计系统

使用 `design-system.yaml` 定义的 token，通过 XAML ResourceDictionary 实现：
- `Colors.xaml`：语义化颜色 token（品牌色、状态色、文字色、背景色、边框色）
- `Sizes.xaml`：间距、圆角、字体大小、触摸目标等尺寸 token
- `Styles.xaml`：基于 token 的全局样式（PageStyle、CardStyle、TitleLabel 等）

### 1.6 DI 注册

`MauiProgram.cs` 中注册所有 ViewModel 和 Page：
- ViewModel 注册为 `AddTransient`
- Page 注册为 `AddTransient`（构造函数注入 ViewModel）

## 2. 功能需求

### 2.1 主页 — 物品列表

**功能点**：
- 按添加时间倒序展示全部有效物品
- 搜索功能：按物品名称、品牌、分类或位置过滤
- 卡片信息：名称、状态徽章、品牌·分类·位置、保质期/持有时长、单价、剩余数量和每日成本

### 2.1.1 临期页 — 到期追踪

**功能点**：
- 仅展示已过期和临期的有效物品
- 搜索状态独立于首页搜索
- 按保质期日期升序展示

### 2.2 物品库

**功能点**：
- 统计汇总卡片：有效花费、有效商品数、全部商品数
- 按分类筛选（横向滚动芯片）
- 物品卡片：图标、名称、状态、单价、剩余数量、每日成本
- 点击进入物品详情页
- 搜索功能
- 左滑删除物品，二次确认后物理删除

### 2.3 添加物品

**功能点**：
- 扫码录入入口暂时隐藏
- 物品信息：名称、分类（Picker）、品牌
- 批次信息：购买日期、单价、存放位置下拉、保质期（含无保质期开关）、初始数量（Stepper）、备注
- 每次购买保存为新的物品记录，不自动合并历史记录

### 2.4 物品详情

**功能点**：
- 物品基本信息：名称、分类、条形码、默认存放位置
- 展示初始数量、剩余数量和消耗记录
- 支持编辑、用掉一件、消耗完成和删除
- 底部操作按钮使用双列全宽布局，避免按钮偏左或宽度不稳定
- 消耗完成后耗尽归档；删除为二次确认后的物理删除

### 2.5 分类管理

**功能点**：
- 显示预置分类和自定义分类
- 新增自定义分类（名称 + 图标）
- 支持分类重命名和图标编辑
- 支持拖拽调整顺序
- 自定义分类支持左滑删除（预置不可删除，有关联物品不可删除）

### 2.5.1 存储位置管理

**功能点**：
- 侧边栏进入存储位置页面
- 新增、重命名和停用存储位置
- 添加/编辑物品时，存放位置从启用位置中下拉选择

### 2.5.2 耗尽归档与消耗记录

**功能点**：
- 侧边栏进入耗尽归档页面，查看剩余数量为 0 的归档物品
- 侧边栏进入消耗记录页面，按消耗时间倒序查看记录
- 消耗记录展示物品名称、消耗类型、数量和日期，不直接暴露内部物品 ID

### 2.5.3 存储管理

**功能点**：
- 完整备份导出为 `.myitems.json`，用于跨手机迁移
- 导出时写入公共 `Download/MyItems` 目录，避免备份文件落在文件管理器不可见的应用私有目录
- Android 9 及以下设备在用户触发导出时申请写入存储权限
- 完整恢复通过系统文件选择器选择备份文件，二次确认后覆盖当前数据
- CSV 导入导出作为兼容工具保留，不作为完整迁移备份

### 2.6 关于

**功能点**：
- 展示应用名称、版本、简介
- 作者、项目地址和主题模式
- 项目地址支持点击后用系统浏览器打开

### 2.7 每日成本计算

**规则**：
- 每日成本 = 总金额（单价 × 初始数量） / 持有天数
- 持有天数 = (今天 - 购买日期).Days
- 无购买日期或持有 0 天时，每日成本 = 总金额
- 有保质期：显示保质期日期
- 无保质期：显示持有时长（如 "持有 60 天"）
- 用户未勾选记录日均成本时，列表不显示日均成本文本

## 4. 交互说明

### 4.1 导航交互

| 操作 | 行为 |
|------|------|
| 左滑屏幕边缘 | 打开侧边栏 |
| 点击侧边栏菜单项 | 切换到对应页面 |
| 点击物品库中物品卡片 | 导航到物品详情页 |
| 点击侧边栏「关于」 | 导航到关于页 |

### 4.2 主页交互

| 操作 | 行为 |
|------|------|
| 点击展开/折叠 | 切换分组展开状态 |
| 输入搜索文字 | 实时按物品名称过滤 |
| 点击批次卡片 | 导航到物品详情（Phase 2 支持编辑） |

### 4.3 添加物品交互

| 操作 | 行为 |
|------|------|
| 勾选「无保质期」 | 保质期 DatePicker 隐藏，清空值 |
| 选择「电子产品」分类 | 无特殊处理 |
| 点击「保存」 | 校验必填项 → 同名检查 → 保存 → 返回主页 |

### 4.4 分类管理交互

| 操作 | 行为 |
|------|------|
| 点击「+ 新增」 | 弹出输入区域，填写名称和图标 |
| 点击「删除」预置分类 | 提示「预置分类不可删除」 |
| 点击「删除」自定义分类 | 确认弹窗 → 删除 |

### 4.5 状态流转

```
物品录入 → 保质期状态实时计算 → 主页分组展示
         ↓
    同名检查 → 关联已有物品 or 新建物品
```

### 4.6 错误处理

| 场景 | 处理 |
|------|------|
| 保存时名称为空 | 表单内显示错误提示 |
| 保存时未选分类 | 表单内显示错误提示 |
| 删除有关联物品的分类 | 弹窗提示无法删除 |
| 数据加载中 | 显示 ActivityIndicator |
| 扫码功能（Phase 1） | 弹窗提示「将在后续版本实现」 |

### 4.7 平台差异

| 项目 | Android |
|------|---------|
| 侧边栏 | FlyoutItem，从左侧滑出 |
| 状态栏颜色 | 遵循系统主题 |
| 返回键 | Shell 自动处理导航栈 |
