WARM PANTRY · UI PROTOTYPE

暖仓 WarmPantry

家庭物品管家 · UI 效果稿（仅视觉与交互演示，非功能实现）。每个页面对应 Flutter 开发中的一屏，可直接对照 Material 3 还原。深色模式跟随系统，或在「我的 → 深色模式」手动切换。

🏠首页仪表盘home.html 📦物品库library.html 🍽️消耗中心consume.html 👤我的mine.html ➕添加物品add-item.html 🧾物品详情detail.html · 多批次/开封/校正 🗂️物品分类categories.html 📍存放位置locations.html ⏰临期预警expiring.html 🗄️耗尽归档archive.html ☁️存储与备份backup.html 🧺关于我们about.html

💡 可交互预览：物品库点卡片进「物品详情」（批次 / 开封 / 余量校正 / 归档引导），卡片「＋」看快捷再入库弹层、「−」后底部出现 5 秒撤销条、消耗中心点行看「记录消耗」弹层、行上「⇄」看余量校正、我的页新增「提醒设置」、添加页可选计量单位与填规格、存储与备份页可试「立即备份」与失败态示意、Esc 或点遮罩关闭弹层。
📐 设计令牌见 assets/warmpantry.css 顶部 CSS 变量（颜色/圆角/阴影/字体），语义口径见 doc/requirement.md。
