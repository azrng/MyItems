暖仓 WarmPantry

家庭物品管家 · UI 效果稿（仅视觉与交互演示，非功能实现）。每个页面对应 Flutter 开发中的一屏，可直接对照 Material 3 还原。深色模式跟随系统，或在「我的 → 深色模式」手动切换。

🏠首页仪表盘home.html 📦物品库library.html 🍽️消耗中心consume.html 👤我的mine.html ➕添加物品add-item.html 🗂️物品分类categories.html 📍存放位置locations.html ⏰临期预警expiring.html 🗄️耗尽归档archive.html ☁️存储与备份backup.html 🧺关于我们about.html

💡 可交互预览：点物品卡片看编辑态、点「＋ 新建」看底部弹层、点物品库分类 chips 看筛选反馈、消耗中心点行看「记录消耗」弹层（点 −1 立即入流水，新流水实时出现在时间线置顶）、Esc 或点遮罩关闭弹层。
📐 设计令牌见 assets/warmpantry.css 顶部 CSS 变量（颜色/圆角/阴影/字体）。
