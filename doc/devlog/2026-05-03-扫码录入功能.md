# 扫码录入功能

> 日期：2026-05-03
> 任务：T020
> 阶段：阶段 1（视图实现）

## 变更内容

实现添加物品页面的扫码录入功能，基于已安装的 `ZXing.Net.Maui.Controls` 包。

### 新增文件
- `src/MyItems/Views/ScannerPage.xaml` — 全屏扫码页面 UI（CameraBarcodeReaderView + 覆盖层）
- `src/MyItems/Views/ScannerPage.xaml.cs` — 扫码逻辑：条码检测、相机权限、导航回传

### 修改文件
- `src/MyItems/MauiProgram.cs` — 添加 `UseBarcodeReader()` 初始化，注册 ScannerPage
- `src/MyItems/AppShell.xaml.cs` — 注册 `"scanner"` 路由
- `src/MyItems/ViewModels/AddItemViewModel.cs` — 更新 ScanBarcodeCommand 导航到扫码页，ApplyQueryAttributes 接收 barcode 参数，新增 ClearBarcodeCommand
- `src/MyItems/Views/AddItemPage.xaml` — 在基础信息区域添加条码展示条（含清除按钮）

## 核心实现

1. 点击"扫码"→ Shell 导航到 ScannerPage
2. ScannerPage 检查设备支持 + 请求相机权限
3. CameraBarcodeReaderView 检测条码后自动返回，通过 Shell 查询参数回传 barcode
4. AddItemViewModel 接收 barcode 并自动填入
5. 不支持的平台（Windows）显示降级提示
