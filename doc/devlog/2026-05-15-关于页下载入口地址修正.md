# 关于页下载入口地址修正

## 本次目标
- 修正关于页 APK 下载入口，避免依赖 `app-release.apk` 这类不稳定的发布产物文件名。

## 核心改动
- 将关于页下载入口地址从 GitHub latest release asset 直链改为 GitHub Releases 列表页。
- 补充测试断言，锁定下载入口应跳转到 `https://github.com/azrng/MyItems/releases`。
- 发布 workflow 构建 Release APK 时显式传入 `--build-name` 和 `--build-number`。
- `--build-name` 来自 `VERSION` 解析后的发布版本，`--build-number` 使用 GitHub Actions 的 `GITHUB_RUN_NUMBER`，确保 Android 覆盖安装能识别新版本。
- 发布 workflow 通过 `--dart-define APP_VERSION` 将同一个版本号注入关于页展示，避免界面仍显示旧的硬编码版本。
- 将 `VERSION` 从 `auto` 调整为 `1.1.0`，后续发布将使用该版本号。
- README 补充本地 Release 构建时同步传入版本号的命令说明。
