# 价格显示与关于下载入口修复

## 本次目标
- 修复价格 `5.99` 在界面显示为 `6.0` 的问题。
- 在关于页增加可跳转浏览器下载 APK 的按钮。
- 让物品详情页内容在宽屏下居中显示。

## 核心改动
- 新增 `formatCurrency`，物品卡片、详情页和物品库统计金额统一显示两位小数。
- 关于页“信息”卡片增加“下载 APK”按钮，复用现有 `my_items/system` 的 `openUrl` 平台通道打开 GitHub latest APK 下载地址。
- 物品详情页主体包裹 `Center` + `ConstrainedBox(maxWidth: 560)`，避免宽屏内容偏左。
- 补充价格格式、关于页入口和详情页居中容器的回归测试。
