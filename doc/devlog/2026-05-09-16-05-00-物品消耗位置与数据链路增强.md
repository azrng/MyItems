# 物品消耗位置与数据链路增强

## 本次目标

- 将购买价格语义调整为单价，补齐剩余数量、消耗记录和耗尽归档。
- 拆分首页与临期页搜索状态，完善分类、存储位置、CSV 和 SQLite 迁移链路。

## 核心改动

- `Item` 增加 `initialQuantity`、`remainingQuantity`，统计改为按单价乘以剩余数量计算。
- 新增 `ConsumptionRecord` 和 `StorageLocation`，支持用掉一件、消耗完成、消耗记录和存储位置管理页。
- 物品删除改为二次确认后的物理删除；耗尽通过 `is_archived` 归档隐藏。
- 临期页使用独立 `expirySearch`，首页、物品库按创建时间倒序，临期页按保质期升序。
- CSV 导入导出扩展为包含单价、购买日期、初始数量、剩余数量、归档等字段，并兼容旧版 `price`、`quantity` 字段。
- SQLite schema 升级到版本 2，补充迁移表、位置表、消耗记录表和数量列补齐逻辑。
- 页面颜色改用 `ColorScheme`，减少深色模式下固定浅色背景导致的可读性问题。
