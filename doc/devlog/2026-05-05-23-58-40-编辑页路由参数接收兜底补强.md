# 编辑页路由参数接收兜底补强

## 本次目标
- 继续修复物品详情进入编辑页时，编辑态已切换但旧值仍未回填的问题。
- 加强编辑页对 `itemId` 路由参数的接收稳定性。

## 核心改动
- 详情页编辑入口改为只传 `itemId` 查询参数，不再依赖复杂对象参数。
- 编辑页恢复 `QueryProperty` 对 `itemId` 和 `barcode` 的简单参数接收。
- 页面 `OnAppearing` 时新增一次基于 `Shell.Current.CurrentState.Location` 的路由查询解析兜底，确保即使 `IQueryAttributable` 或 `QueryProperty` 生命周期表现不一致，也能再次把 `itemId` 传入 ViewModel。

## 修改文件
- `src/MyItems/ViewModels/ItemDetailViewModel.cs`
- `src/MyItems/Views/AddItemPage.xaml.cs`

## 校验情况
- 已执行：`dotnet build src\MyItems\MyItems.csproj -f net10.0-windows10.0.19041.0`
- 结果：构建通过，0 错误
- 仍有项目既有 `MVVMTK0045` 警告，未在本次处理范围内

## 风险或遗留项
- 本次是对路由参数接收链再补一层兜底，仍需 Android 真机手动验证“详情页 -> 编辑页 -> 旧值回填”。
- 若设备上仍不生效，下一步需要直接在目标机上查看导航生命周期日志，确认 `itemId` 是否真的到达页面。
