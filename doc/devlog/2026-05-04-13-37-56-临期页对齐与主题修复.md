# 临期页对齐与主题修复

## 本次目标

- 修复临期页中“已过期”分区与“临期提醒”分区左侧不对齐的问题。
- 修复过期状态角标在浅色背景下文字看不清，以及手动主题切换后现代化 UI 资源未同步的问题。

## 核心改动

- 移除已过期分区额外左侧缩进，让两个分区标题与列表卡片保持同一左边界。
- 新增 `ModernWarningBadgeStyle`、`ModernErrorBadgeStyle`，并使用独立状态容器色与文字色提升可读性。
- 扩展 `App.ApplyTheme` 对 `Modern*` 资源的明暗主题刷新。
- 手动切换主题时由 `AboutViewModel` 主动调用应用主题刷新逻辑。
