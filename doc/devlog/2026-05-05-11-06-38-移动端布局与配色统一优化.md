# 移动端布局与配色统一优化

## 本次目标
- 根据移动端 App 视角分析结果，优化页面密度、状态配色职责与关键触摸热区。

## 核心改动
- 将危险/过期色从品牌珊瑚粉中拆分为独立危险红，成功色从次级薄荷色中拆分为稳定绿。
- 收紧 `ModernCardStyle` 默认圆角、内边距和阴影，降低列表与工具区的卡片厚重感。
- 将物品库分类筛选胶囊、分类页图标选择与排序/删除按钮补足到更适合移动端的触摸尺寸。
- 将扫码页和部分危险操作中的硬编码品牌/反色文本改为语义化资源引用。
- 同步更新 `design-system.yaml`，使设计 token 与当前实现配色保持一致。
