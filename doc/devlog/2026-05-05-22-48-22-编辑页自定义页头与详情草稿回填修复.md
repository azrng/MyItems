# 编辑页自定义页头与详情草稿回填修复

## 本次目标
- 去掉编辑页顶部大块空白和底部 TabBar 干扰。
- 为从详情页进入编辑页增加一条不依赖二次查询的旧值回填链路。

## 核心改动
- 为编辑页关闭 Shell 顶部导航栏和底部 TabBar，改为页内自定义返回头部，减少顶部留白。
- 新增 `IEditItemDraftService`，从详情页点击编辑时先缓存当前详情 DTO，再导航到编辑页。
- 编辑页优先消费详情草稿回填字段；若草稿不存在，再退回按 `itemId` 查数据库。
- `ItemDisplayDto` 补充 `TrackDailyCost`，保证编辑页从详情草稿回填时字段完整。
