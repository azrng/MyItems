# XAML 构建错误修复

## 本次目标

修复构建时报出的 MAUI XAML 解析错误，包括无法解析 `SizeAnimator`、`CheckBox.Content` 不存在以及 `FlexLayout.ItemsSource` 属性不存在。

## 核心改动

- 移除扫码页中非 MAUI 标准类型 `SizeAnimator`，保留扫描线静态视觉元素。
- 将高级搜索页的 `CheckBox.Content` 改为 `HorizontalStackLayout` 包裹 `CheckBox` 与 `Label`。
- 移除分类页和物品库页 `FlexLayout` 上不支持的 `ItemsSource` 属性，保留正确的 `BindableLayout.ItemsSource`。

## 修改文件

- `src/MyItems/Views/ScannerPage.xaml`
- `src/MyItems/Views/AdvancedSearchPage.xaml`
- `src/MyItems/Views/CategoryPage.xaml`
- `src/MyItems/Views/ItemLibraryPage.xaml`

## 校验情况

- 已执行：`dotnet build .\src\MyItems\MyItems.csproj -f net10.0-windows10.0.19041.0 --no-restore`
- 结果：构建通过，0 个错误。
- 已复查：`SizeAnimator`、`CheckBox.Content`、错误的 `FlexLayout.ItemsSource` 写法不再存在。
- 仍有既有 `MVVMTK0045` warning，本次未处理。

## 风险或遗留项

- 当前环境缺少 Android SDK，未能执行 Android 目标构建。
- 扫码页扫描线暂时为静态线条，后续若需要动画应改用 MAUI 支持的 code-behind 动画或合法 VisualState/Behavior 实现。
