# 编辑页顶部空白与保存复修

## 本次目标
- 修复详情页进入编辑页后顶部仍有大块空白的问题。
- 修复编辑后保存未体现到详情页的问题。

## 核心改动
- 将详情页编辑入口恢复为 Shell 路由对象参数传递，避免 Android modal 页面栈带来的额外顶部占位。
- 移除添加 / 编辑页外层无效的 0 高占位布局。
- 保存按钮改为先读取当前页面原生控件值并同步到 `AddItemViewModel`，再执行保存命令。
- 保存链路增加调试日志，便于确认保存前字段、分类与数量。
- 详情页 `OnAppearing` 时刷新当前物品，确保编辑页返回后重新读取数据库。
