# 首页存储管理与图标完善

## 本次目标

- 将 Flutter 首页调整为按添加时间倒序展示全部物品。
- 保持临期页只展示临期和已过期内容。
- 补齐存储管理入口和页面，并为 Android 应用接入图标。

## 核心改动

- 新增 `AppStore.homeItems` 和 `ItemRepository.getHomeItemDisplays`，首页按 `createdAt DESC` 展示全部未归档物品。
- 首页搜索改为搜索全部物品，临期分组展示保留在临期页。
- 抽屉新增「存储管理」入口，新增 `StoragePage`，支持导出 CSV、按路径导入 CSV、清空数据二次确认。
- Android Manifest 接入 `@drawable/app_icon`，新增与 MAUI 图标一致的 vector drawable。
- 补充首页排序和存储管理入口 widget 测试。
