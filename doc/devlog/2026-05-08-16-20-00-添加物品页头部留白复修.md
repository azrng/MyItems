# 添加物品页头部留白复修

## 本次目标

- 根据截图继续修复添加物品和编辑物品页面标题栏下方仍有大块空白的问题。
- 在不改保存、编辑回填和数据链路的前提下，移除导致首屏占位过大的独立头卡，并清理上一轮负位移补丁。

## 核心改动

- 隐藏 `AddItemPage` 的 Shell NavBar，并设置 `SafeAreaEdges="None"`，改为页面内自绘紧凑红色标题栏，避免 Shell 标题栏与页面内容区 inset 继续叠加。
- 同时在 XAML、构造函数和 `OnAppearing` 中确认 `NavigationPage.HasNavigationBar=False`，兜底非 Shell 原生导航栏占位。
- 增加页面内返回按钮，返回逻辑仍使用 `Shell.Current.GoToAsync("..")`。
- 将页面改为确定两行布局：第 0 行固定 68 高标题栏，第 1 行承载滚动表单和底部保存区，避免覆盖布局继续引入不可见占位。
- 删除原首屏“添加物品”独立头卡，让“基础信息”卡成为标题栏下方的首个内容块。
- 移除 `TranslationY="-170"` 负位移补丁，将滚动内容顶部内边距控制为 `8`，并为底部固定按钮预留滚动安全空间。
- 移除上次排查遗留的 `[AddItemPage]` 布局诊断日志，保留原生控件同步逻辑。
- 在 `ui-AGENTS.md` 补充连续视觉问题失败后的规则：必须做根因回顾，禁止继续使用负位移掩盖问题，未取得截图证据前不得宣称视觉问题已修复。
