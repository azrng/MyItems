# UI 优化与 Syncfusion 组件替换

> 2026-05-02 17:00

## 本次目标

1. 日均成本按批次独立控制（添加物品时可开关）
2. 底部 Tab 精简为 2 个（主页 + 物品库），物品库右侧 SfNavigationDrawer 侧边栏
3. 物品库统计"有效商品花费"改为"个人资产"，分类栏用 SfChipGroup 替换
4. 主页搜索栏右侧添加"＋"按钮
5. 首页批次卡片显示批次标签（BatchLabel）

## 核心改动

### Syncfusion 初始化
- MauiProgram.cs 添加 `.ConfigureSyncfusionToolkit()`

### 日均成本批次开关
- Batch、AddItemDto、BatchDisplayDto 新增 `TrackDailyCost` 属性
- AddItemViewModel 新增 `trackDailyCost` 字段，SaveAsync 中赋值
- MockDataService：显示器批次设置 `TrackDailyCost = false`，DTO 映射更新
- AddItemPage：SfSwitch 替换原生 CheckBox 作为日均成本开关

### 导航精简
- AppShell：TabBar 从 3 个改为 2 个（主页 + 物品库），移除分类 Tab 和添加 FlyoutItem
- AppShell.xaml.cs：新增 CategoryCommand，注册 CategoryPage 路由

### 首页改造
- MainPage：搜索栏改为 Grid 布局，右侧添加"＋"按钮
- MainViewModel：新增 GoToAddCommand
- 批次卡片 MultiBinding 新增 BatchLabel 字段
- 日均成本 Label 用 `IsVisible="{Binding TrackDailyCost}"` 条件显示

### 物品库重构
- ItemLibraryPage：SfNavigationDrawer 包裹（DrawerPosition=Right, DrawerWidth=280）
- 侧边栏：DrawerHeaderView（设置标题）+ DrawerContentView（分类管理、关于）
- 分类栏：SfChipGroup 替换手动 HorizontalStackLayout + Button
- 统计卡片："有效商品花费" → "个人资产"
- ItemLibraryViewModel：Categories 首项从 null 改为"全部" Category（Guid.Empty），适配 SfChipGroup 绑定
- ItemLibraryPage.xaml.cs：移除 OnCategoryClicked，新增 OnSettingsClicked（ToggleDrawer）
