# 物品库加载状态修复

## 本次目标
- 检查并修复物品库界面一直显示加载的问题，确保初始化、刷新、分类筛选和搜索回传不会让加载状态悬挂。

## 核心改动
- 移除 `ItemLibraryViewModel` 构造函数中的后台初始化，改为由刷新命令统一触发可等待的初始化流程。
- 增加初始化锁与加载锁，避免页面出现、搜索筛选回传、分类默认选中并发触发重复加载。
- 初始化分类时抑制默认分类选择造成的额外数据加载，减少进入页面时的竞态。
- 数据加载失败时清空当前列表摘要、关闭加载状态，并弹出明确错误提示。
- 在 SQLite 初始化后补充运行时 schema 兜底：当 `Items` 表存在但缺少 `Name` 列时自动添加，避免模型字段与旧表结构不一致导致物品库读取失败。
- 同步修复物品库卡片右侧状态胶囊显示不完整的问题，保证移动端状态文案不被挤压。
