# 提醒图标与状态配色修复

## 本次目标

- 替换顶部 emoji 铃铛，避免系统 emoji 风格与应用界面不一致。
- 修复首页“临期 5 天”状态徽标文字对比度不足。
- 检查当前主色、状态色和文本色是否存在明显可读性风险。

## 核心改动

- 使用 MAUI 原生 `Border` / `BoxView` 组合绘制简洁线框提醒图标，不再依赖 emoji。
- 保留通知红点，但缩小尺寸并与新图标视觉统一。
- 将状态文字转换器中的临期颜色改为 `ModernWarningText`，已过期颜色改为 `ModernErrorText`。
- 将警告/临期色从亮黄文字调整为浅琥珀背景 + 深琥珀文字，提高浅色主题下的可读性。
- 同步更新手动主题切换时的 `ModernWarning*` 与 `AppExpiring*` 资源刷新。

## 修改文件

- `src/MyItems/AppShell.xaml`
- `src/MyItems/Converters/StatusToColorConverter.cs`
- `src/MyItems/Resources/Styles/Colors.xaml`
- `src/MyItems/App.xaml.cs`
- `TASK.md`

## 校验情况

- 已执行：`dotnet build .\src\MyItems\MyItems.csproj -f net10.0-windows10.0.19041.0`，通过。
- 已尝试：`dotnet build .\src\MyItems\MyItems.csproj -f net10.0-android`，因本机命令行缺少 Android SDK 失败，错误为 `XA5300: 找不到 Android SDK 目录`。

## 配色检查结论

- 当前珊瑚主色与白色标题文字对比可接受，暂不建议大面积换主色。
- 薄荷色加号按钮在白底上识别清楚，但后续若承载小号文字应避免白字小字。
- 主要风险集中在警告/临期状态：亮黄文字在浅黄底或白底上对比不足，本次已收敛为深琥珀文字。

## 风险或遗留项

- 尚未在 Android 真机上确认线框提醒图标的最终渲染精度。
- Windows 编译剩余 MVVM Toolkit WinRT/AOT 警告为既有提示，与本次配色修复无直接关系。
