# 添加编辑页头部与分类选中修复

## 本次目标

- 修复添加物品和编辑物品页面头部出现明显空白的问题。
- 修复物品库顶部分类切换后数据已筛选但指定分类未保持选中高亮的问题。

## 核心改动

- `AddItemPage` 移除显式 `Shell.NavBarIsVisible`、`SafeAreaEdges` 和代码侧 `NavigationPage.SetHasNavigationBar` 强制设置，改回与物品详情页一致的 Shell 页面结构，避免额外顶部占位叠加。
- `SelectableCategory` 改为继承 `ObservableObject`，`IsSelected` 改为 `[ObservableProperty]` 公共属性，确保分类按钮 `DataTrigger` 能收到选中态变更通知。
- 新增 `MyItems.Tests` 轻量测试项目，覆盖分类选中态属性变更通知，避免同类 UI 状态回归。
