# 编辑页导航回填链路收口修复

## 本次目标
- 修复从物品详情进入编辑页时，编辑态标题已切换但表单旧值仍为空的问题。
- 收口编辑页初始化链路，避免同一表单同时被多套传值方式覆盖。

## 核心改动
- 将详情页进入编辑页的方式改为单一 `ShellNavigationQueryParameters` 传参，直接传递 `ItemDisplayDto` 对象作为编辑草稿。
- 编辑页仅通过 `IQueryAttributable` 接收参数；若已收到完整 `editDraft` 对象，则直接回填字段，不再继续并行走静态草稿、页面实例直塞和二次路由字符串回填。
- 保留 `itemId` 查询作为缺失数据时的数据库兜底，但新增保护：若当前页面已经完成同一 `itemId` 的回填，则不再重新触发加载。
- 更新 `application-AGENTS.md`，补充“同一编辑页只保留一条主初始化链路”的回顾规则，避免再次出现多路回填互相覆盖。
