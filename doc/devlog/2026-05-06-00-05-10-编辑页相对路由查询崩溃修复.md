# 编辑页相对路由查询崩溃修复

## 本次目标
- 修复 Android 上进入编辑页时，由相对路由读取查询参数触发的崩溃。

## 核心改动
- 定位到 `AddItemPage.ApplyRouteFallbackParameters()` 直接读取 `Uri.Query`，而 Android 当前 Shell 状态给的是相对 URI，触发 `InvalidOperationException`。
- 将查询参数解析改为兼容绝对 URI 和相对 URI 的字符串解析方式，避免再次访问相对 URI 的 `Query` 属性。

## 修改文件
- `src/MyItems/Views/AddItemPage.xaml.cs`
- `TASK.md`

- 结果：构建通过，0 错误
