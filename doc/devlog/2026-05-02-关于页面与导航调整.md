# 关于页面与导航调整

## 本次目标

新增关于页面、调整导航结构、增加每日成本计算、更改导出格式为 Excel。

## 核心改动

1. **关于页面**：新增 AboutPage + AboutViewModel，展示应用名称、版本、简介、作者、技术栈、项目地址
2. **导航结构调整**：
   - 物品库移到最后一个 Tab
   - 关于从 Tab 移到侧边栏（Flyout）
   - 右上角汉堡菜单入口
3. **每日成本计算**：BatchDisplayDto 增加 HoldingDays、DailyCost、DailyCostText、HoldingText 字段
   - 有保质期：展示保质期日期
   - 无保质期：展示持有时长（天数）

4. **导出格式**：从 JSON 改为 Excel（.xlsx），使用 ClosedXML 库
5. **设计文档更新**：导航结构、关于页面、导出格式、技术栈
