# 完整备份恢复与消耗记录页面

## 本次目标

- 将数据迁移能力从 CSV 表格导入导出升级为完整备份与恢复。
- 修复物品详情页底部操作按钮偏左，并补齐耗尽归档和全局消耗记录入口。

## 核心改动

- 新增 `.myitems.json` 完整备份格式，包含分类、存储位置、物品、消耗记录、设置和导出元信息。
- 存储管理页改为「完整备份与恢复」为主，完整备份通过系统保存文件流程导出到用户可见位置，CSV 导入导出保留为兼容工具。
- 完整恢复支持选择备份文件并二次确认，导入后覆盖当前本地数据并补齐预置分类、预置位置。
- 新增耗尽归档页，用于查看剩余数量为 0 的归档物品。
- 新增消耗记录页，按时间展示消耗类型、物品名称、数量和日期，不再显示内部物品 ID。
- 物品详情页底部操作改为两行双列全宽布局，避免按钮区域偏左。
