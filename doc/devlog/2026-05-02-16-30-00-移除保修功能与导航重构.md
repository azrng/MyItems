# 移除保修功能 + 导航重构

> 2026-05-02 16:30

## 本次目标

1. 移除项目中所有保修相关代码和文档引用
2. 重构导航结构：底部 TabBar + 物品库显示统计卡片 + 首页仅展示过期/临期

## 核心改动

### 保修移除
- 删除 `WarrantyStatus` 枚举文件
- 从 Batch、AddItemDto、BatchDisplayDto、ItemDisplayDto 移除保修字段
- 从 StatusHelper 移除 `CalculateWarrantyStatus` 和 `GetWarrantyStatusText`
- 从 MockDataService 移除保修数据映射，新增 `DailyCostText` 计算
- 从 AddItemViewModel 移除 `WarrantyDate`、`ShowWarrantyField`
- 从 XAML 视图移除保修标签和输入区（ItemDetailPage、AddItemPage、ItemLibraryPage）
- 从 AboutViewModel 更新描述文案
- 设计文档和需求文档同步移除保修引用

### 导航重构
- AppShell：从 4 个 FlyoutItem 改为 TabBar（主页/物品库/分类）+ FlyoutItem（添加）
- MainPage：移除统计卡片，过滤只显示 Expired 和 Expiring 分组
- MainViewModel：移除统计属性，新增 ExpiryStatus 过滤逻辑
- ItemLibraryPage：新增统计汇总卡片（有效花费/有效商品/全部商品）
- ItemLibraryViewModel：新增统计属性和加载逻辑
