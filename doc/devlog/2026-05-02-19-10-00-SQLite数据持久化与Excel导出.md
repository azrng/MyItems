# SQLite 数据持久化 + Excel 导出

**日期**: 2026-05-02 19:10
**任务 ID**: T013
**阶段**: 阶段 2 — 应用层与数据实现
**负责人**: Claude Code

---

## 目标

将 `MockDataService` 静态内存存储替换为 SQLite 真实持久化，支持数据在应用重启后保留；新增 ClosedXML Excel 导出功能。

## 变更概述

### 模型层
- `Category`、`Item`、`Batch` 添加 `[PrimaryKey]`、`[Table]`、`[Indexed]` sqlite-net 特性
- `CategoryDto` 改为 `ObservableObject`，`IsActive` 属性可观察，支持 SfSwitch 绑定自动持久化

### 服务层
- **`IDataService`**（新建）：定义所有数据操作接口
- **`SqliteDataService`**（新建）：SQLite 实现 + ClosedXML Excel 导出
  - 数据库路径：`FileSystem.AppDataDirectory/myitems.db`
  - 首次启动仅写入 6 个预置分类，物品和批次为空
  - Excel 导出到 CacheDirectory，通过 MAUI Share API 分享

### DI 注册
- `MauiProgram.cs`：`IDataService` 注册为 Singleton，启动时自动 `InitializeAsync()`

### ViewModel 层
- 所有 ViewModel（Main、ItemLibrary、AddItem、ItemDetail、Category）构造函数注入 `IDataService`
- `MockDataService` 静态调用全部替换为 `await _dataService.XxxAsync()`
- `LoadData` 改为 `LoadDataAsync`，使用 async/await

### Android 平台
- `MainActivity.OnCreate` 添加 `SQLitePCL.Batteries_V2.Init()` 初始化原生 SQLite 库

### UI 变更
- `ItemLibraryPage.xaml` 侧边栏新增"📊 导出 Excel"菜单项
- `CategoryPage.xaml` 命令绑定名更新为 `Async` 后缀（SortUpAsyncCommand 等）

## 包依赖
- 新增 `SQLitePCLRaw.bundle_green 2.1.*`（原生 SQLite 库）

## 验证
- Windows 目标编译通过，0 错误
- Android 目标需真机验证（SQLite 初始化 + 数据持久化）

## 风险
- Android FastDev 模式下 SQLitePCLRaw 程序集加载有警告，已通过显式 `Batteries_V2.Init()` 解决
- 首次启动后原有 Mock 数据丢失（预期行为，用户已确认仅保留预置分类）
