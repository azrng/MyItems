# 简化分类管理页定位卡退

## 本次目标
- 继续处理点击“分类管理”后卡死或卡退的问题。
- 先把分类管理页降到最小可用结构，排除复杂 XAML 模板、刷新容器和跨作用域绑定导致的运行时崩溃。

## 核心改动
- 分类入口恢复使用 `Shell.Current.GoToAsync("category")`，保留打开失败时的异常提示。
- `CategoryPage.xaml` 降为新增输入、分类列表、删除按钮与加载指示器，移除图标选择器、启用开关、排序按钮、编辑入口、`RefreshView` 和 DataTemplate 跨作用域命令绑定。
- `CategoryPage.xaml.cs` 增加 `InitializeComponent` 兜底，若 XAML 初始化失败则显示错误页，避免直接把应用带崩。
- 删除按钮改为 code-behind 事件转发到 ViewModel 命令，业务校验仍由 `CategoryViewModel.DeleteCategoryAsync` 负责。
