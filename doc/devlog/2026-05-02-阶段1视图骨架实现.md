# 阶段 1 视图骨架实现

## 本次目标

实现「我的物品」App 阶段 1 全部视图骨架，包含 5 个页面、Mock 数据、DTO 类、设计系统资源。

## 核心改动

1. **项目结构**：创建 .NET MAUI 解决方案（.NET 10 + Android），包含完整目录结构
2. **设计系统资源**：从 `design-system.yaml` 提取颜色、尺寸、样式 token，创建 `Colors.xaml`、`Sizes.xaml`、`Styles.xaml`
3. **Models + DTOs**：`Item`、`Batch`、`Category` 实体，`ExpiryStatus`/`WarrantyStatus` 枚举，`BatchDisplayDto`、`ItemDisplayDto`、`ExpiryGroupDto`、`AddItemDto`、`CategoryDto` 契约类
4. **Helpers + Converters**：`StatusHelper`（保质期/保修期状态计算）、`ExpiryStatusToTextColorConverter`、`ExpiryStatusToBgColorConverter`、`InvertedBoolConverter`、`StringNotNullOrEmptyConverter`
5. **Mock 数据**：`MockDataService` 提供预置分类、模拟物品和批次、组装 DTO
6. **5 个页面 + ViewModel**：
   - 主页（到期追踪）：按状态分组展示，支持展开/折叠、搜索
   - 物品库：分类筛选 + 物品列表
   - 添加物品：表单录入 + 扫码入口（Phase 2 实现）
   - 分类管理：预置/自定义分类 CRUD
   - 物品详情：物品信息 + 批次列表 + 添加/删除批次
7. **Shell 导航**：底部 4 Tab + ItemDetail 路由
