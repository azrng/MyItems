# 状态色令牌统一修复

## 本次目标
- 修复状态颜色转换器与页面中 `App*`、`Modern*` 状态色 token 混用的问题。

## 核心改动
- `ExpiryStatusToTextColorConverter` 改为统一读取 `ModernErrorText`、`ModernWarningText`、`ModernSuccessText`、`ModernInfoText`。
- `ExpiryStatusToBgColorConverter` 改为统一读取 `ModernErrorContainer`、`ModernWarningContainer`、`ModernSuccessContainer`、`ModernInfoContainer`。
- 在 `Colors.xaml` 补齐 `ModernSuccessContainer`、`ModernSuccessText`、`ModernInfoContainer`、`ModernInfoText`。
- 在 `App.xaml.cs` 的主题切换中同步设置新增 Modern 状态 token 的浅色和深色值。
- 临期页分区数量徽标从 `AppExpiringBgColor`、`AppExpiredBgColor` 改为 `ModernWarningContainer`、`ModernErrorContainer`。
