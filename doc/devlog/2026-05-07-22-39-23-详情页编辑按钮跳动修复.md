# 详情页编辑按钮跳动修复

## 本次目标

修复从物品详情页点击“编辑”按钮后，底部按钮区会先向下移动再进入编辑页的问题。

## 核心改动

- 详情页进入编辑页改为 Shell 路由参数导航，继续通过 `editDraft` 传递当前物品数据，避免直接创建编辑页实例导致导航链路不一致。
- 编辑命令允许并发执行，避免命令执行期间自动切换禁用态触发原生按钮状态抖动。
- 打开编辑页期间暂停详情页 `OnAppearing` 刷新，避免导航过渡阶段重新加载数据导致底部栏重算。
- 详情页声明隐藏 Shell TabBar，与编辑页保持一致，避免从详情页到编辑页时底部 TabBar 可见性变化造成底部操作区下沉。
