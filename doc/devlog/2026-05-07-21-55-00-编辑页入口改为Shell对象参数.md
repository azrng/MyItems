# 编辑页入口改为 Shell 对象参数

## 本次目标

- 修复编辑物品页在真机/模拟器上仍未回填数据、顶部留白无变化的问题。

## 核心改动

- 将详情页编辑入口从 `Navigation.PushAsync(page)` 手动创建页面，改为 `Shell.Current.GoToAsync("add", ShellNavigationQueryParameters)` 并传入 `editDraft` DTO。
- 编辑页继续通过 `IQueryAttributable` 统一接收编辑草稿，避免手动页面实例、Shell 当前路由和兜底解析互相覆盖。
- 删除 `AddItemPage` 中读取 `Shell.Current.CurrentState.Location` 的路由兜底解析。
- 编辑页内容外层增加顶部对齐 Grid，降低外层容器居中或占位对内容首屏位置的影响。
