# Flutter Android 迁移

## 本次目标

- 在 `flutter` 分支新增 Flutter Android 版本源码，覆盖「我的物品」核心 Android 使用链路。
- 保留现有 MAUI 工程作为迁移参考，不删除 `src/`、`tests/` 和解决方案文件。

## 核心改动

- 新增 `pubspec.yaml`、`analysis_options.yaml` 和 Flutter Android 壳工程目录 `android/`。
- 新增 `lib/models.dart`，迁移分类、物品、展示 DTO、过期状态、日均成本和搜索匹配逻辑。
- 新增 `lib/repository.dart`，实现 SQLite 初始化、预置分类、物品 CRUD、软删除、分类约束、统计、过期分组和 CSV 导入导出。
- 新增 `lib/app_store.dart`，使用 `ChangeNotifier` 承载页面状态、刷新、搜索、分类筛选、保存和删除逻辑。
- 新增 `lib/main.dart` 与 `lib/pages.dart`，实现 Material 3 主题、底部导航、抽屉入口、主页、物品库、详情、添加编辑、分类管理和关于页。
- 新增 `test/status_helper_test.dart`，覆盖过期状态、状态文本、日均成本和搜索匹配。
- 更新 `.gitignore`，忽略 Flutter 构建产物和本地 Android 配置。
- 更新 `README.md`，补充 Flutter Android 目录、环境要求、首次构建命令和当前验证限制。
- 新增 `doc/design/flutter-android-migration-plan.md`，记录迁移计划。
- 更新 `doc/Flutter-Android-环境配置.md`，整理为面向 Android 新手的 Windows Flutter Android 环境配置与真机调试教学指南。
- 更新 `TASK.md`，新增并推进 T052 到 `DONE`。
