# Android 真机调试修复

## 本次目标

修复 Android 真机（API 27）部署后启动崩溃的系列问题。

## 核心改动

1. **AndroidManifest.xml**：移除 `<uses-sdk>` 标签，由项目文件 `SupportedOSPlatformVersion` 控制
2. **MauiProgram.cs**：移除不存在的字体文件引用（`OpenSans-Regular.ttf`、`OpenSans-Semibold.ttf`）
3. **AppShell.xaml**：移除 Windows 专用 `Segoe MDL2 Assets` 字体图标
4. **MainPage.xaml**：`x:Static` 引用 Converter 改为 `StaticResource`
5. **Styles.xaml**：`FontAttributes="SemiBold"` 改为 `Bold`（MAUI 不支持 SemiBold）
6. **Styles.xaml**：`MergedDictionaries` Source 路径修正（`Resources/Styles/Colors.xaml` → `Colors.xaml`）
7. **StatusHelper.cs**：`GetExpiryStatusText` 增加 null 安全检查
8. **4 个 XAML 文件**：`Margin`/`Padding` 中混用字面量和 `StaticResource` 的 Thickness 替换为硬编码数值
9. **3 个 ViewModel**：`DisplayAlert` 改为 `DisplayAlertAsync`
10. **创建设计文档**：`doc/design/设计文档.md`
11. **更新需求文档**：技术栈 .NET 9→10、项目结构、依赖包同步
