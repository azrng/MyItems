# 物品库加载卡住与性能排查

## 本次目标
- 修复物品库偶发持续 loading 的状态恢复问题。
- 排查物品库分类切换、搜索、高级筛选等交互中的性能热点。
- 检查系统中相邻加载链路是否存在同类风险。

## 核心改动
- 物品库加载失败时先恢复 `IsLoading` / 空状态，再异步展示错误提示，避免弹窗未返回导致页面一直 loading。
- 物品库分页加载增加 `try/finally`，确保 `IsLoadingMore` 在异常路径也会复位。
- 将物品库数据库刷新与本地筛选拆开：分类切换、搜索输入、高级搜索返回不再重复触发 SQLite 全量查询与 DTO 映射。
- 删除物品后同步更新物品库缓存与统计，避免本地筛选模式下列表短暂残留。
- 补充物品库 ViewModel 单元测试，覆盖加载失败、弹窗阻塞、并发刷新、本地筛选、删除缓存更新与空状态。
