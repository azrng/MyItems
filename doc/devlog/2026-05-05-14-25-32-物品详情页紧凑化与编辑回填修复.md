# 物品详情页紧凑化与编辑回填修复

## 本次目标
- 修复物品详情页出现无意义空图标行、页面布局过空，以及点击编辑后信息未稳定回填的问题。

## 核心改动
- 为 `ItemDisplayDto` 补充 `Barcode` 与详情页展示用属性，保证条码信息有真实数据来源。
- 详情页条码区域改为仅在有条码时显示，并以“条码”字段呈现，避免只显示手机图标的空行。
- 重构详情页布局为紧凑头部、基础信息、购买与期限、备注四个区域，减少大面积留白。
- 编辑入口改为使用 `ShellNavigationQueryParameters` 传递 `itemId`，避免字符串路由参数传递不稳定。
- 添加页分类加载增加锁与已加载标记，编辑加载会等待分类完成后再设置选中分类，避免初始化竞态冲掉回填信息。
- 详情页加载失败时显示用户可见错误文案。
