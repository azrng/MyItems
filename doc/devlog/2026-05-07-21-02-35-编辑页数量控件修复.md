# 编辑页数量控件修复

## 本次目标

- 修复编辑物品页数量区域在 Android 上显示为两个大灰块、数量值不清晰的问题。

## 核心改动

- 将原生 `Stepper` 替换为页面内自绘的紧凑三段式数量控件：减号按钮、数量值、加号按钮。
- 新增 `DecreaseQuantityCommand` 与 `IncreaseQuantityCommand`，将数量限制在 1 到 999。
- 撤销临时测试工程与 MAUI 替身，避免用不真实的测试环境污染项目结构。

## 修改文件

- `src/MyItems/Views/AddItemPage.xaml`
- `src/MyItems/ViewModels/AddItemViewModel.cs`
- `doc/devlog/2026-05-07-21-02-35-编辑页数量控件修复.md`

## 校验情况

- 已执行：`dotnet build src\MyItems\MyItems.csproj -f net10.0-windows10.0.19041.0 --no-restore`，Windows 目标构建通过。
- 未保留单元测试：当前 ViewModel 直接依赖 MAUI Shell 类型，普通 .NET 测试工程需要伪造 MAUI 类型，验证价值不足且容易误导。
