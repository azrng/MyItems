# 分类页加载优化与添加页调整

- 时间：2026-05-04 16:25
- 阶段：阶段 3
- 负责人：Claude Code

## 本次目标

1. 优化分类页面加载性能，解决进入分类页时的卡顿问题
2. 临时注释添加物品页的扫码功能
3. 缩小添加物品页保存按钮区域

## 核心改动

### 分类页加载优化

- 移除分类页面中显示每个分类下物品数量的功能
- 优化 `GetCategoryDtosAsync()` 方法，不再执行 `COUNT(*) GROUP BY CategoryId` 聚合查询
- 新增 `CategoryHasItemsAsync()` 方法，在删除分类时实时检查是否有物品关联
- 简化 `SubtitleText` 显示逻辑：预置分类显示"预置"，自定义分类显示"自定义"

### 添加物品页调整

- 注释掉扫码按钮和条码显示卡片（保留代码以备后续恢复）
- 压缩保存按钮区域：Padding 改为 `12,10`，Spacing 改为 `8`
- 缩小保存按钮高度：从 56 降至 46
