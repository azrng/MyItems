# 详情页路由崩溃修复

## 本次目标
- 修复 Android 真机从物品库进入详情页时 `Relative routing to shell elements is currently not supported` 崩溃。

## 核心改动
- 从 `AppShell.xaml` 移除详情页顶层 `ShellContent`，避免 `itemdetail` 被识别为 Shell 可视层级元素。
- 在 `AppShell.xaml.cs` 中将 `itemdetail` 注册为普通详情页路由，保留 `GoToAsync("itemdetail?itemId=...")` 的导航栈行为。
