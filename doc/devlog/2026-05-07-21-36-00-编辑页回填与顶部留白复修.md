# 编辑页回填与顶部留白复修

## 本次目标

- 修复从物品详情进入编辑页后，表单字段再次显示为空的问题。
- 压缩编辑页顶部异常留白，避免 Shell / NavigationPage 顶栏占位影响页面首屏。

## 核心改动

- `PrepareForEdit()` 改为先同步把详情 DTO 写入 ViewModel，再保留一次延后补水草稿，降低 Android 原生输入控件初始化阶段把默认值反写回 ViewModel 的风险。
- `AddItemPage` 构造和 `OnAppearing()` 阶段都显式隐藏 Shell NavBar、TabBar 与 NavigationPage 导航栏。
- 有直接注入的编辑草稿时，跳过 Shell 当前路由兜底解析，避免详情页旧路由参数覆盖编辑草稿。
- 编辑页根节点显式 `Padding="0"`，减少平台导航容器带来的额外顶部留白。
