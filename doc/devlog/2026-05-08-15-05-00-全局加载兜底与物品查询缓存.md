# 全局加载兜底与物品查询缓存

## 本次目标
- 上线前收敛首页、临期页、物品库和标题栏提醒的重复全量查询。
- 补齐首页、临期页加载失败时的 loading / refreshing 状态复位。
- 明确新增、编辑、删除、导入、清空、分类变更后的缓存失效边界。

## 核心改动
- 新增 `IItemQueryCache` / `ItemQueryCache`，缓存 `GetItemsWithStatisticsAsync` 的物品 DTO 与统计快照，并用锁合并并发加载。
- 首页、临期页、物品库和标题栏提醒统一读取 `IItemQueryCache`，避免页面切换时重复全量查询、映射和统计。
- 首页、临期页加载失败时使用 `try/finally` 复位 `IsLoading` / `IsRefreshing`，错误提示改为异步展示，避免 UI 状态被弹窗阻塞。
- 物品新增/编辑、详情删除、列表删除、导入 CSV、初始化测试数据、清空数据、导入数据库、分类增删改/启用状态变化后统一失效物品查询缓存。
- 补充缓存服务、首页、临期页、物品库缓存读取与异常路径单元测试。
